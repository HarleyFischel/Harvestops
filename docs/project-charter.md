# Project charter and scope

HarvestOps is a synthetic produce-operations control plane demonstrating senior application-development practices: operational visibility, guarded workflows, SQL Server integration, secure delivery, and maintainable examples.

In scope: shipment KPIs and exceptions, dock execution, purchasing approvals, synthetic ingestion, permission-filtered operating knowledge, SQL Server/Azure SQL compatibility, container delivery, and representative MCP/legacy/performance examples. Out of scope: production identity tenancy, real farm/customer data, automatic cloud provisioning, and a claim of affiliation with any produce company.

Success means a fresh clone can run the demo, workflows enforce server-side rules, SQL mode is explicit and documented, images build for ARM64 and AMD64, and verification distinguishes evidence from account-dependent work.
