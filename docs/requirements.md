# Requirements and acceptance criteria

The portfolio acceptance criteria are represented by the tracked checklist and validation report. Core acceptance is: a fresh demo setup starts the Dash application, seeded KPIs are coherent, filters affect the same scope, status and purchasing workflows enforce role/state/version rules, exports are authorized, imports are idempotent, and tests provide negative coverage. Infrastructure acceptance additionally requires external SQL Server, Docker, browser, and Azure checks; those are clearly separated when unavailable.
