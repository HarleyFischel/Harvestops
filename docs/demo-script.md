1. Start the demo and show the synthetic-data banner, the compact Operations overview, filter scopes, KPI definition help, and service-category chart.
2. Switch to the shipment board, explain server-side pagination, select SHP-1004, and update it as demo.operator. Show the selected-record detail, valid transitions, audit history, and stale-version protection.
3. Attempt the same change as demo.viewer and show the server-side denial; show the protected export.
4. Create and submit a purchase request from the queue/detail workflow, switch to demo.approver, approve a pending request, then show audit history in the service/test evidence.
5. Search the knowledge assistant and point out citations and search-vs-generated-answer labeling.
6. Show the SQL migrations, pyodbc repository, external-database Compose, and x86-only SQL Server stack.
7. Show the GitHub Actions workflow, Bicep template, MCP tools, legacy React sample, and validation report.
